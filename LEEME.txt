VERSIÓN SIN CARPETA ICONS

Subir a GitHub estos archivos directamente en la raíz del repositorio:
- index.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

No hace falta carpeta icons.

IMPORTANTE:
Si al abrir la app aparece texto raro con PNG, significa que index.html fue reemplazado por una imagen.
La solución es subir este index.html y confirmar que GitHub muestre el archivo como texto HTML.
